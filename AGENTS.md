# Replion

Replay your coding agent sessions ... make your AI demos predictable! Built with Gleam and Lustre.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for `gahjelle/replion`, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
